# task-tracker

A proof-of-concept app written by the web-app-skills plugin, one Claude Code session per ticket:
scaffold, tasks list, task detail, dashboard, then a restyle to match `design/`. How each step
went, with its prompt and report, is in
[`docs/evidence/poc/history.md`](../../docs/evidence/poc/history.md).

- **Dashboard** (`/`): task counts from `GET /tasks/stats`, a completion bar, and the tasks due
  in the next 7 days.
- **Tasks** (`/tasks`): status filter and title search kept in the URL, a create form with
  validation and server (422) errors next to the fields, status changed inline from the list.
- **Task detail** (`/tasks/:id`): edit every field (`PATCH`), delete with confirmation
  (`DELETE`), and a "Task not found" state; a 404 on save or delete returns to the list.
- Every data view has loading, error with retry, empty and success states. Every component has a
  test file and a Storybook story.

There is no backend: [MSW](https://mswjs.io/) handlers in `src/features/*/mocks.ts` answer the
API in tests, in Storybook and in the browser.

## Run it

Needs Node ≥ 22.22 and pnpm 11 (`corepack enable` picks the pinned version).

```bash
pnpm install
cp .env.example .env.local   # then set VITE_API_MOCKING=true
pnpm dev                     # http://localhost:5173
pnpm check                   # lint, typecheck, test, build, Storybook build
pnpm storybook               # every component state on http://localhost:6006
```

## Demo build

A static build that answers the API in the page (no service worker) and routes in memory, so it
runs on any static host:

```bash
VITE_DEMO=true VITE_API_URL=https://demo.invalid/api pnpm exec vite build --base ./ --outDir dist-demo
```

This is the only part not written by a skill (`src/mocks/demo.ts` and a few lines in
`src/main.tsx`). Data resets on reload.

The project conventions the skills followed are in [`CLAUDE.md`](CLAUDE.md), generated by the
`code-skeleton` skill. The copied skills and companions (`.claude/skills/`, `skills-lock.json`)
are left out of this folder; install the plugin to get them.
